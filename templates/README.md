# templates/

Aquí van los archivos `.html` que Flask renderiza (motor Jinja2).
Cuando conectemos el módulo de Usuarios, aquí se adaptarán los mockups que
ya tienes en tu carpeta `ARKHE/` (login, dashboard, clientes, proyectos,
apartamentos, ventas, pagos, usuarios), convirtiéndolos de HTML estático
a plantillas dinámicas que muestran datos reales de la base de datos.
